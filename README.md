# NET-TestBench · actualizaciones

Este repositorio lo leen los bancos de prueba del taller de **NET Gaming** para actualizarse solos.
Tiene únicamente el programa listo para usar (`NET-TestBench.ps1`), su `LEEME.txt` y `version.json`
(versión, cambios y SHA-256 de cada archivo, que el banco verifica antes de reemplazarse).

No tiene la clave del taller ni ningún dato de clientes. El código fuente está en un repositorio privado.
No subir archivos a mano: se publica con `publicar.py` desde el repositorio del código.
